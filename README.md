# UI-тесты ok.ru — Playwright + pytest

ДЗ №4: 5 автотестов на Playwright с паттерном Page Object.

## Тесты

1. Форма входа видна незалогиненному пользователю
2. Неверный логин/пароль — ошибка «Неправильно указан логин и/или пароль»
3. «Показать пароль» показывает пароль открытым текстом
4. «Не получается войти?» открывает восстановление доступа
5. «Зарегистрироваться» открывает экран VK ID

## Структура

```
conftest.py         — фикстуры: браузер, контекст, страница
pages/              — Page Object'ы, локаторы спрятаны внутри классов
tests/test_login.py — тесты
```

## Запуск

Нужен установленный Google Chrome (тесты используют его, а не браузер Playwright).

```
pip install -r requirements.txt
python -m pytest tests/ -v
```

В тестах только фейковые учётные данные.

# UI-тесты ok.ru — Playwright + pytest

ДЗ №4: автотесты на Playwright с паттерном Page Object.

## Тесты

Без логина (работают всегда):

1. Форма входа видна незалогиненному пользователю
2. Неверный логин/пароль — ошибка «Неправильно указан логин и/или пароль»
3. «Показать пароль» показывает пароль открытым текстом
4. «Не получается войти?» открывает восстановление доступа
5. «Зарегистрироваться» открывает экран VK ID

Под залогиненным аккаунтом (нужны креды в `.env`):

6. Логин с реальными кредами открывает ленту
7. В ленте есть посты
8. Из шапки открывается свой профиль

## Настройка

```
pip install -r requirements.txt
copy .env.example .env
```

В `.env` вписать свои `OK_LOGIN` и `OK_PASSWORD`. Файл в `.gitignore`,
в репозиторий не попадает; без него тесты 6–8 просто пропускаются.

## Запуск

```
python -m pytest tests/ -v
```

Нужен установленный Google Chrome — браузер Playwright не скачивается.

## Структура

```
conftest.py         — фикстуры: браузер, контекст, логин-сессия
pages/              — Page Object'ы, локаторы спрятаны внутри классов
tests/test_login.py — анонимные тесты
tests/test_logged_in.py — тесты под логином
```
